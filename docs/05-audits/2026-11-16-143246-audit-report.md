## 二、发现清单（按严重度）

### S1 结构性（4 条，阻断交付）

#### F-01 按钮点击后「成功 / 失败 / 不可用」在界面上完全不可见
- 现象：按钮写入 `data-state="done|missing|failed"`，但 CSS 中没有任何 `[data-state]` 规则命中竖条按钮；2 秒后状态被定时器清除，痕迹彻底消失。
- 证据：E-02、E-03
- 影响：用户点「压缩上下文」这类官方命令，若通道降级或失败，界面毫无变化。用户只会说「点了没反应」，然后重复点击。DSH 桌面版没有 DevTools，控制台里的降级日志用户看不到。
- 三专业交叉：视觉 V5.3（状态视觉缺失）、交互 I2.1/I3.1/I5.2、动效 M4.2/Z2.3
- 修复指向：补 `done`/`failed`/`missing` 三态样式 + 角标（不只靠颜色）+ `:active` 按下反馈 + `aria-live` 播报

#### F-02 设置页两套保存语义并存，拨开关会静默覆盖未保存的按钮改动
- 现象：两个开关一碰即落盘；按钮清单必须点「保存」。更严重的是 `persistSwitches` 写入的是**存储里的旧清单**，用户在改了按钮之后顺手拨开关，改动被静默回退。
- 证据：E-05
- 影响：这是数据丢失。用户会说「我改的东西没了」。
- 交叉：交互 I6.1/I6.2
- 修复指向：`persistSwitches` 必须带上当前 draft 的清单

#### F-03 「恢复默认」无确认，一次误点清空全部自定义
- 现象：`reset()` 直接 `removeItem`，无 `confirm`、无后果说明、不检查未保存草稿，且按钮紧挨「添加/保存」。
- 证据：E-04
- 影响：不可逆的数据丢失，误触概率不低。
- 交叉：交互 I5.1/I10.1、产品 P10.2
- 修复指向：加确认框并写明「会删除 N 个按钮，无法撤销」

#### F-04 竖条无高度约束，按钮一多就被视口裁掉且无法滚动
- 现象：`.dshQuickRail` 只写 `top:50% + translateY(-50%)`，没有 `max-height`、没有 `overflow`。设置页允许无限添加按钮、导入也没有条数上限。
- 证据：E-01
- 影响：加满 20 个按钮时总高约 702px，笔记本屏幕或拉矮窗口时首尾按钮永远看不见也点不到，界面没有任何提示。
- 交叉：视觉 V2.4、V4.3
- 修复指向：`max-height:calc(100vh - 32px)` + `overflow-y:auto`

### S2 体验回退（8 条，阻断交付）

| 编号 | 现象 | 证据 | 影响 |

## 三、产品域专项结论

| 问题 | 结论 |
|---|---|
| 这个竖条该不该存在？ | **该存在，但定位需要收窄。** 斜杠菜单是「查找式」，竖条是「肌肉记忆式」，两者不重复。真正的问题不在重复，而在**可发现性**——105 枚纯图标 + 原生 `title` 气泡，用户无法知道哪个图标对应哪条命令（P7.1/P7.2） |
| 三种按钮类型的密度是否合理？ | **不合理。** 30px 纯图标条无法承载三类行为完全不同的动作，用户无法预判点击后果（P3.2） |
| 「自动收起」默认开启但未告知？ | **需要告知。** 改变默认行为必须让用户在设置页看到明确说明，目前有开关但缺少「为什么」的说明（P5.2） |
| 一轮修 5 次才生效说明什么？ | 说明**验证通道缺失**：没有可观测的运行时证据，只能靠用户手动重启试错。这是产品级缺陷，不是单次实现失误（P10.1/P10.3） |

## 五、未验证清单

1. **真实运行环境下的观感**：全部 JS/CSS 结论来自代码与无头 Chrome 静态渲染，**未在运行中的 DSH 窗口里复看**。深色主题、Retina 与非 Retina 下的实际观感未验证。
2. **图标对比度**：`--dsw-alias-*` 令牌运行时注入，源码内无定义，无法静态计算对比度。需在真实渲染中取 `getComputedStyle` 实测。
3. **读屏实际播报**：只确认了 `role="status"`/`aria-live` 属性存在，未用 VoiceOver 实际收听。
4. **多会话并存时竖条是否重叠**：竖条注册在 session 级槽但用 `position:fixed` 定位，官方同时挂载多份会话时可能渲染多条叠在同一像素。未实测。
5. **拖拽侧栏时的跟随平滑度**：定位用 `Math.round`，`right` 落在 .5 边界时可能跳 1px，未实测。
6. **设置页在窄窗口下的换行**：`dshQuickSet_row` 一行 7 个元素，窄窗口下的压缩未验证。
