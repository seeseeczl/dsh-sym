# 全局指令

## 语言

默认使用中文与我交流,包括解释、总结、提问和报错说明。**思考过程(thinking)也使用中文**,
最终输出同样使用中文。执行过程中的步骤说明、工具调用的描述、阶段性进度汇报,一律使用中文。
会话标题(会话列表/历史记录中显示的摘要标题)也必须使用中文;无论是聊天、协作还是代码类会话,一律如此。

**这条偏好与模型无关,必须始终生效。** 无论当前选用哪个 provider 或模型(官方登陆 / Ecarx /
DeepSeek / GLM / 本地部署,以及以后新增的任何模型),都要保持中文交流、中文思考、中文输出。
只有当我的提问本身是其它语言,或我明确要求换语言时,才跟着切换。

代码、命令、文件路径、API 名称等技术内容保持原文,不强制翻译。
Git 提交信息遵循各仓库现有提交历史的语言习惯(例如 ASECLI 历史提交为英文,则继续用英文)。

## 版本号更新规则（用户 2026-10-16 定）

**三段、每段最多两位数字（0–99）；每次更新只在第三段 +1。**

- 正常递增是 `+0.0.1`：`1.8.0` → `1.8.1` → `1.8.2`……平时**不动**第一、二段。
- 满 99 才进位：`1.8.99` → `1.9.0`；`1.99.99` → `2.0.0`；到 `99.99.99` 为止。
- **不遵循语义化版本**：新增功能、破坏性变更同样只 `+0.0.1`，不因改动性质跳段。
- 不要用 `npm version minor` / `npm version major`，也不要按 semver 推断下一个版本号。
- 项目内若已有更具体的发布口径（例如 `CHANGELOG.md` 顶部的「发布规则」），**以项目内为准**；
  本节是项目没有另行规定时的默认值。
