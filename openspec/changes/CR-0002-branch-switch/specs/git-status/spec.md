# FR-12｜点分支名切换本地分支

本文件是 CR-0002 对基线的**增量**；基线回填前不写入 `openspec/specs/`。

## 目标与范围

- 用户/角色：在本机用 DSH 写代码的人，仓库里有多个本地分支。
- 触发条件：会话头部胶囊上的分支名被点击（且本地分支数 > 1）。
- 成功结果：菜单里选中另一个分支后，工作目录真的切过去，胶囊读数立刻更新。
- 范围外：新建/删除/重命名分支、远端分支、stash、pull/push、冲突解决。

## Requirements

### Requirement: 分支数大于一时可点分支名切换

系统 SHALL 在本地分支数 > 1 时把胶囊上的分支名渲染为可点击控件，弹出一个本地分支菜单；
选中一个非当前分支后，**在该会话的工作目录里执行 `git switch`**，成功后立即刷新读数。
分支数 ≤ 1 时分支名 SHALL 保持为不可点击的纯文本。

#### Scenario: 成功切换

- **WHEN** 工作区干净、菜单里选中另一个分支
- **THEN** 工作目录切到该分支，胶囊的分支名与新分支的增删行数立刻更新，菜单关闭

#### Scenario: 工作区改动会被覆盖（交给 git 拒绝）

- **WHEN** 目标分支与当前工作区的改动冲突
- **THEN** git 拒绝切换，菜单里原样显示 git 的解释，工作区与当前分支**保持不变**

#### Scenario: 分支名不合法或不存在

- **WHEN** 请求里的分支名不在本地分支清单里（含以 `-` 开头、过长、含控制字符）
- **THEN** 宿主在跑任何 git 命令之前拒绝（400），工作区不受影响

#### Scenario: 只有一个分支

- **WHEN** 仓库只有当前分支
- **THEN** 分支名不可点击，不出现任何菜单

### Requirement: 插件不得在切换中丢弃用户的工作区改动

系统 SHALL NOT 使用 `-f` / `--discard-changes` / `reset` / `stash` 等会改动工作区内容的手段；
切换失败时工作区 SHALL 保持原样。切换只允许执行 `git switch`（带 `--` 终止选项，argv 传参）。

#### Scenario: 失败即无副作用

- **WHEN** 任意一次切换失败
- **THEN** 当前分支与工作区文件内容都与请求前一致

## 非功能与验收

- 性能/可靠性：分支清单与 `status` / `diff` 同一次读取返回；切换成功后宿主读缓存按目录失效，客户端立即重读。
- 安全/权限：分支名先与本地清单白名单比对，再经 argv 传递，永不经过 shell；只接受 `POST`（在 Connection 鉴权栅栏内）。
- 可观测性：切换失败经 `noteDegrade` 记录一次；菜单里展示 git 的原始解释。
- 无障碍/兼容性：菜单为 `role="menu"` / `role="menuitem"`，Esc 与点击外部关闭，当前分支带可读标记。
- 关联回归：`REG-0002`（见 `tasks.md`）。
